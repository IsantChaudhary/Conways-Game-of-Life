# Source Code

This directory contains the Java source code for Conway’s Game of Life.

## Package Structure

- **application** — Contains the main application entry point.
- **gui** — Contains the graphical user interface, including the main window, game grid, and user controls.
- **model** — Contains the game logic, cell states, and generation updates.
- **exceptions** — Contains custom exceptions used by the application.

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
